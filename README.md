# Personal Portfolio

A Vite + React personal portfolio site with client-side routing.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The dev server runs at [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Routes

- `/` — Home
- `/about` — About
- `/contact` — Contact

## Project structure

```
src/
  components/
    Nav.jsx          # Shared navigation
  pages/
    Home.jsx
    About.jsx
    Contact.jsx
  data/
    projects.js      # Project data for the home page
public/
  map/               # Placeholder for a map image
```

## Build

```bash
npm run build
npm run preview
```
